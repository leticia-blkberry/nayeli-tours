# Nadxheelii Tours website

Static one-page site (Spanish) for Nadxheelii Tours, a guide in San José del Pacífico, Oaxaca
(Facebook page: https://www.facebook.com/Nayetours). The repo is still named `nayeli-tours`.

## Repository rules

- This site lives **only** in `leticia-blkberry/nayeli-tours`. All work, commits and pushes go here.
- **Never use the `leticia-blkberry/solar-care` repository** for anything — do not read, change, commit to or push to it, even if it is attached to the session.

## Project notes

- Plain HTML/CSS/JS, no build step; published with GitHub Pages from `main` at https://leticia-blkberry.github.io/nayeli-tours/
- `index.html` — all sections; `css/styles.css` — magical night-forest theme; `js/main.js` — WhatsApp number (`WHATSAPP_NUMBER`), menu, stars, floating spores and cursor sparkles.
- Brand: name "Nadxheelii Tours", circular logo in `images/logo.jpg`. Services: Senderismo, Temazcal, Medicina con hongos (the site also lists Hospedaje).
- Colors: only the logo's forest green `#0b2d1c` and cream `#f3eee1`, plus blends between them and darker greens (tokens in `:root` of `css/styles.css`).
- WhatsApp: +52 951 106 7780 (`wa.me/529511067780`).
- The hero's mountains, clouds and fir-tree layers are generated by `tools/landscape.py` (run `python3 tools/landscape.py index.html` after editing it; it rewrites that part of the hero SVG).
- The hero plays an intro on page load (logo slides in, landscape layers rise, text slides in, clouds/moon/birds appear, mushrooms grow) and a typewriter line cycles the logo's services; styles under "Intro de la portada" in `css/styles.css`, typing in `js/main.js`.
- Hero media: `videos/amanecer.mp4` (client's TikTok sunrise clip, trimmed to drop the TikTok end screen, cropped to remove the watermark, muted) with poster `images/amanecer-poster.jpg`; it does not autoplay under reduced motion.
- Gallery photos go in `images/galeria/` with the file names listed in `README.md`; missing photos fall back to illustrations.
- Keep all motion disabled under `prefers-reduced-motion`, and keep the 18+ / wellbeing messaging for the mushroom experiences.
