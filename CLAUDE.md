# Nadxheelii Tours website

Static one-page site (Spanish) for Nadxheelii Tours, a guide in San José del Pacífico, Oaxaca
(Facebook page: https://www.facebook.com/Nayetours). The repo is still named `nayeli-tours`.

## Repository rules

- This site lives **only** in `leticia-blkberry/nayeli-tours`. All work, commits and pushes go here.
- **Never use the `leticia-blkberry/solar-care` repository** for anything — do not read, change, commit to or push to it, even if it is attached to the session.

## Project notes

- Plain HTML/CSS/JS, no build step; published with GitHub Pages from `main` at https://leticia-blkberry.github.io/nayeli-tours/
- `index.html` — all sections; `css/styles.css` — magical night-forest theme; `js/main.js` — WhatsApp number (`WHATSAPP_NUMBER`), menu, stars, floating spores and cursor sparkles.
- Brand: name "Nadxheelii Tours", circular logo in `images/logo.jpg`. Services: Senderismo, Temazcal, Medicina con hongos (the site also lists Hospedaje).
- Colors: only the logo's forest green `#0b2d1c` and cream `#f3eee1`, plus blends between them and darker greens (tokens in `:root` of `css/styles.css`).
- Fonts: headings use Montserrat (closest free Google Font to the logo lettering), uppercase with wide letter-spacing; accent words lighter (400) like "TOURS" in the logo. Body text is Inter.
- WhatsApp: +52 951 106 7780 (`wa.me/529511067780`).
- The hero's mountains, clouds and fir-tree layers are generated by `tools/landscape.py` (run `python3 tools/landscape.py index.html` after editing it; it rewrites that part of the hero SVG).
- The hero plays an intro on page load (logo slides in, landscape layers rise, text slides in, clouds/moon/birds appear, mushrooms grow) and a typewriter line cycles the logo's services; styles under "Intro de la portada" in `css/styles.css`, typing in `js/main.js`.
- Glowing mushroom clusters live in two `svg.hero-shrooms` corner layers (bottom-left, and bottom-right mirrored) outside the landscape SVG, so they always grow in from the screen edges; they reuse the `#shroom`/`#tuft` symbols defined in the landscape SVG.
- Hero media: `videos/amanecer.mp4` (client's TikTok sunrise clip, trimmed to drop the TikTok end screen, cropped to remove the watermark, muted) with poster `images/amanecer-poster.jpg`; it does not autoplay under reduced motion.
- Gallery photos go in `images/galeria/` with the file names listed in `README.md`; missing photos fall back to illustrations.
- Keep all motion disabled under `prefers-reduced-motion`, and keep the 18+ / wellbeing messaging for the mushroom experiences.
- Section order (decision-first): Hero → Servicios → Experiencia (cards + interactive journey) → Opiniones → Galería → Bienestar → Preguntas frecuentes (`#preguntas`, native `<details>` + FAQPage JSON-LD; keep the JSON-LD in sync with the visible answers) → Eventos → Contacto.
- FAQ and service copy must not invent facts (prices, durations, meeting point, policies); point to WhatsApp until the client provides them.
- Reservations are **requests only**: `#reservar` form validates and opens WhatsApp with a message marked as an unconfirmed request; it never books. Optional read-only Google Calendar (free/busy) embed via `GOOGLE_CALENDAR` in `js/main.js` (hidden while empty). Never use Google appointment schedules / booking pages or anything that lets visitors book directly.
- Section order now ends: … Eventos → Solicita tu fecha (`#reservar`) → Contacto; the header "Reservar" button goes to `#reservar`.
- Footer must always include the credit line "Design by DigitalBlackBerry" (`.credit`).

## Accessibility and mobile (keep these working)

- Target WCAG 2.2 AA. Check with axe-core (zero violations) plus keyboard, screen-reader and 320px-wide checks after changes.
- Skip link "Saltar al contenido" → `main#contenido`; visible `:focus-visible` outline on every control.
- "Pausar animaciones" button (`.motion-toggle`, WCAG 2.2.2) pauses video, spores, typewriter, journey autoplay and all CSS animations; new animations must register with `motionHooks` in `js/main.js` or be CSS animations. The hero intro must skip to its final state when paused (`html.motion-off` rule).
- Closed mobile menu is `visibility: hidden` (not tabbable); Escape closes it. Links with `target="_blank"` get a hidden "(se abre en una pestaña nueva)" note automatically.
- No horizontal scrolling at 320px; text ≥ 12px; tap targets ≥ 44px for standalone links and buttons.
